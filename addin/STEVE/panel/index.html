Update & restart STEVE?

STEVE will verify the downloaded update, wait for its work and Fusion commands to finish, then restart itself. Fusion and your documents stay open. Your account data and saved chats are kept, and the current chat reopens. If the new version cannot start, the previous files are restored.
KEEP WORKING TOWARD AN OUTCOME

Your job

STEVE continues until the job is complete, paused, blocked, or limited. Editing the objective starts fresh usage tracking. Stop also pauses the job.

Slash commands

/jobs <objective> — create or replace
/jobs — status and controls
/jobs edit — edit objective and budget
/jobs pause — pause work
/jobs resume — continue
/jobs clear — remove job, keep chat

Ollama server

STEVE uses http. The port defaults to 11434. Add an API key only if that server requires one. Saving reconnects Ollama and reopens the current chat when the server answers.

Added after the host and port. STEVE still calls /api and /v1 under a prefix. A query such as ?think=false is for a gateway that turns reasoning off on the URL. Put secrets in the API key field.
