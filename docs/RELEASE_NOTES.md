EVE's first Windows preview brings a ChatGPT-powered engineering assistant into Autodesk Fusion.

## Download and install

Download **EVE-0.1.0-windows-x64.zip** from the assets below. Extract the whole ZIP, close Fusion, then run **Install EVE.exe**. Reopen Fusion, enable EVE in Scripts and Add-ins if needed, and sign in with ChatGPT.

The ZIP includes the Codex runtime, installer, and installation guide. You do not need a separate Python, Node.js, Codex installation, or API key. GitHub's **Source code** downloads do not contain the installer or runtime.

## Included

- Python-driven modeling, document queries, CAM inspection, and assembly workflows through Fusion's API.
- Automatic selection context and a pinned task document.
- Reference images through paste or the attachment button, plus viewport capture for verification.
- Streaming chat, mid-task steering, session history, and saved model/effort preferences.
- Fusion API help, web search, and optional local debug logs.

This is an unsigned Windows x64 preview. Live Fusion verification is ongoing; save your design before trying generated changes. The download's SHA-256 checksum is included as a separate asset.
